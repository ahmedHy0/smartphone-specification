# Smartphone Specification

This repository contains a smartphone specifications dataset and an analysis notebook for exploring mobile device features and market trends.

## Contents

- `Mobiles Dataset (2025).csv` - A CSV dataset containing smartphone specifications, including hardware details, screen specs, camera features, battery capacities, pricing, and other device attributes.
- `smartphone Specification .ipynb` - A Jupyter notebook for data exploration, cleaning, analysis, and visualization of the smartphone dataset.

## Purpose

The goal of this project is to analyze smartphone specifications and compare devices across various categories. It can be used to:

- Examine trends in smartphone features for 2025
- Compare specifications such as processor, RAM, storage, camera setup, battery size, and display type
- Visualize relationships between price and device capabilities
- Identify popular smartphone configurations and feature trade-offs

## Getting Started

1. Open `smartphone Specification .ipynb` in Jupyter Notebook or JupyterLab.
2. Load `Mobiles Dataset (2025).csv` into the notebook.
3. Run the notebook cells to explore the dataset and generate charts or summaries.

## Notes

- Make sure the notebook and CSV file remain in the same folder so the notebook can load the dataset using a relative path.
- If you want to extend the analysis, add more notebook cells for additional feature engineering, filtering, and modelling.
